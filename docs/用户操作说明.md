# TimeFlow 用户操作说明

TimeFlow 是一款离线时间管理 App。无需注册账号，任务、日程和备份文件只保存在当前设备。

## 首次使用

打开 App 后，建议先进入底部导航的 **设置**，完成“提醒与权限”中的授权。每一项都可以点击，App 会打开对应的系统设置页；返回 App 后状态会自动刷新。

### 通知权限

点击 **通知权限**，在系统弹窗或系统设置中允许 TimeFlow 发送通知。没有通知权限时，任务和日程都无法提醒。

### 日程强提醒

点击 **日程强提醒**，进入“日程强提醒”通知类别设置，确认以下项目已开启：

- 允许通知；
- 悬浮通知或横幅通知；
- 锁屏显示；
- 振动。

日程强提醒不会播放铃声，到点后会振动，最长持续 60 秒。

### 锁屏弹出提醒

点击 **锁屏弹出提醒**。

- Android 14 及以上：在“全屏提醒”或“全屏 Intent”页面允许 TimeFlow。
- Android 13 及以下：系统通常没有独立的全屏提醒开关，请在“日程强提醒”的通知设置中允许悬浮通知和锁屏显示。

日程到点时，App 会请求点亮屏幕，并在锁屏上显示提醒页面。系统勿扰模式、通知设置和手机厂商的后台限制仍可能影响效果。

### 准时提醒

点击 **准时提醒**，允许 TimeFlow 使用精确闹钟。未允许时，提醒仍会安排，但可能因省电策略延迟。

### vivo / iQOO 手机补充设置

在设置页可点击 **vivo 后台弹出界面** 和 **vivo 锁屏后台运行** 打开相关系统入口。还请在手机系统中检查：

1. **设置 → 应用与权限 → 权限管理 → 自启动**：允许 TimeFlow 自启动；
2. **设置 → 电池 → 后台耗电管理**：允许 TimeFlow 后台运行或后台高耗电；
3. **设置 → 通知与状态栏 → 锁屏通知**：允许锁屏显示，并开启“收到锁屏通知时亮屏提醒”；
4. TimeFlow 的通知设置中：允许“后台弹出界面”（若系统提供该项）、悬浮通知和锁屏显示。

不同 OriginOS 版本的菜单名称可能略有不同，可在系统设置内搜索“自启动”“后台弹出界面”或“锁屏通知”。

## 制定日程

日程有开始和结束时间，可设置到点或提前提醒；任务则用于待办事项，日程不会计入任务完成率。

1. 在“今天”或“计划”页点击 **新建**；
2. 在顶部选择 **日程**；
3. 输入标题，按需填写备注；
4. 在“时间安排”中依次选择开始日期、开始时间、结束日期和结束时间；
5. 在“提醒与重复”中选择提醒方式和重复频率；
6. 在“整理”中选择分类；
7. 点击右上角 **保存** 或底部 **保存安排**。

从“今天”新建日程时，默认开始时间为当前时间后的下一个 15 分钟整点，默认时长一小时；从“计划”页的其他日期新建时，默认是 09:00 至 10:00。

### 日期和时间滚轮

点击日期会出现年、月、日三列滚轮；点击开始时间或结束时间会出现小时、分钟两列滚轮。滚动到所需值后点击 **完成**。

### 设置提醒

点击“提醒”会从屏幕底部打开选择器，可选：

- 不提醒；
- 到点提醒；
- 提前 5、15、30 或 60 分钟。

选中选项后点击 **确定** 才会应用。没有具体时间的任务不能安排提醒。

### 设置重复

点击“重复频率”可选不重复、每天、工作日或每周。选择“每周”后，可勾选发生的星期；选择重复后，还可设置“重复至”日期。

编辑或删除重复日程时，App 会询问只影响本次，还是影响本次及以后。

## 到点后的操作

日程提醒页会显示日程标题、剩余时间和两个操作：

- **稍后提醒**：停止本次振动，10 分钟后再次提醒；
- **关闭**：只关闭本次提醒，不会把日程标记为完成。

日程无人处理 60 秒后会自动停止振动，并留下一条未处理通知。多个同时到点的日程会合并显示，可选择全部稍后提醒或全部关闭。

## 常见问题

### 锁屏后只振动或只亮屏，没有提醒页面

依次检查“日程强提醒”的悬浮通知、锁屏显示和通知重要性；再检查“锁屏弹出提醒”和“准时提醒”。vivo / iQOO 设备还需按上文开启后台弹出界面、自启动和后台耗电管理。完成设置后重新打开 TimeFlow，再新建两分钟后的日程进行测试。

### 任务没有提醒

只有设置了具体日期和时间的任务才可以提醒。无日期或全天任务不会安排系统提醒。
