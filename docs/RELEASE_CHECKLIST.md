# 交付与发布

当前交付为内部试用版：功能代码及自动化测试已提供，不能把模拟器验证等同于计划中的全部真机发布验收。

## 安装

将 `artifacts/TimeFlow-1.0.0-test.apk` 传至安卓 8.0 及以上手机，通过系统安装器安装。首次进入设置开启通知；需要准时提醒时开启“闹钟和提醒”特殊权限。权限操作返回后应用会刷新状态并重建未来提醒。

开发者可以使用：

```sh
adb install -r artifacts/TimeFlow-1.0.0-test.apk
```

APK 使用开发测试签名；不要对它进行商店正式发布。后续改用不同签名时通常不能覆盖安装，请先手动导出备份。安装包不附带测试数据。

## 正式发布前

1. 完成 `TESTING.md` 的实体设备、最低版本、提醒时效与备份选择器验收。
2. 使用组织安全管理的 keystore 设置 Release 签名，不把密钥及密码提交源码。
3. 更新版本号，重新执行静态分析、单元、Widget、集成及原生测试。
4. 生成签名 APK/AAB，检查权限和隐私说明，开展小范围试用。
5. 根据目标商店准备应用截图、介绍与审核资料后提交。

本版本无后端，不需要部署服务器；没有旧数据需要迁移。以后修改 SQLite schema 时必须编写显式迁移，并使用已有备份/数据库验证升级。
